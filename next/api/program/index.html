    Programs and sessions¶

    The protocol a program implements so qccompute can find, plan, place and run it, and the sessions callers use to evaluate one molecule at many geometries. A program registers one object (an instance) under the qccompute.programs entry point group. The protocols are structural and what a program returns for capabilities and plan may be a plain mapping, so a program without subprograms never imports qccompute. What programs share as data (Request, Accuracy, ProgramError, Frame) is in qcdata. Design: the program interface.

    qccompute.testing.check_program(program, inputs) checks the contract (install qccompute[testing] to validate keywords against the program's JSON Schema), and qccompute.testing.toy is a complete example program (Lennard-Jones).

    qccompute.program.Session ¶

    The same program and molecule at many geometries, warm-started.

    Opened from a ProgramInput (mychem.Session(inp) directly, or SessionProgram.open_session under qccompute). The input pins the atoms, charge, multiplicity, model and keywords (method, basis, grids, precision) for the session's lifetime, so all its evaluations lie on one potential energy surface; anything else needs a new session. A request may vary only how tightly it converges (qcdata.Request.accuracy), which history it continues (lineage, seed, commit) and which optional outputs it adds (outputs). Contract:

    • Results are Frame objects: the structure evaluated, its SinglePointData, and the request's own warnings and record (an SCF escalation, a stability probe, a fallback), with the shared warm_start at the top of the record. program and program_version are the session's.
    • Lineages are any JSON value, keyed by qcdata.lineage_key; None is the default lineage. A lineage's history is its last committed success.
    • A failed request raises ProgramError (with its failed frame) from compute; compute_many runs every request and then raises qcdata.ProgramErrors holding the failures and every frame in order. The session stays usable and the lineage's history is untouched: a caller may retry a smaller step.
    • A hessian request returns the energy and gradient too.

    qccompute.program.RunContext(*, threads: int | None = None, gpus: Sequence[str] = (), memory_gib: float | None = None, device_memory_gib: float | None = None, timeout: float | None = None, plan: Plan | None = None, scratch: Path | None = None, runner: _Subprograms | None = None, progress: ProgressCallback | None = None) ¶

    What a runner gives one calculation: its share of the machine and its subprograms.

    Runners make it and always pass one to Program.compute; a program reads its fields. In a list, a calculation's share of its runner is the larger of its share of the threads and its share of the GPUs (with k calculations per GPU, each counts 1/k of a GPU). The resource keywords threads, memory_gib and device_memory_gib are what a calculation asks for, and the runner grants them, at most what it has (for a subprogram, what its parent was granted).

    A program uses the smaller of its own request (a resource keyword) and the grant, or the grant when it requested nothing; a request capped by the grant is a resource_capped warning, not an error.

    Attributes:

    Name Type Description
    threads

    CPU threads granted: what the input asks for (its threads keyword, else plan.resources.threads; all of them when that is None), at most the runner's. None: not granted (a direct call).
    gpus tuple[str, ...]

    Identifiers of the GPUs granted (as for CUDA_VISIBLE_DEVICES: indices or UUIDs); device_ordinals gives this process's CUDA ordinals.
    memory_gib

    Host memory granted (GiB). A calculation run alone (one input, a session) gets all of the runner's memory, or as a subprogram all of its parent's grant (a session opened with threads= gets the part of it those threads are of the parent's).     Memory granted on each GPU (GiB): 1/k of the GPU when k calculations may share it (per_gpu), at most a subprogram's parent's grant. The input's device_memory_gib keyword replaces it, at most the GPU's memory or that grant. A batch gets the share. None: not known or no GPU granted.

    The runner's plan of this input, when it made one, so the program need not plan again; exactly what program.plan(input) returned.

    Where the program reports what it is doing while it runs, if the caller listens; None when nobody does, so a program checks it before building an event. Call it with a small JSON object, the program's own (qcopt: one per step, {"event": "step", "step": 12, "energy": ...} in qcdata's units); the caller receives it with "path" added, the program names from the caller's input down to this one.     timeout: float | None property ¶

    Seconds the calculation has left, if the caller set a limit.

    A program that starts processes kills them when it runs out and fails with kind timeout; one that loops (SCF cycles, optimizer steps) checks it. The runner kills a program in a worker process when it runs out, but cannot stop one in its own process: there the limit is the program's to honour, and the runner only refuses to start its subprograms afterwards (ctx.compute, ctx.session and the session's requests fail with kind timeout). Subprograms get what is left.

    scratch: Path property ¶

    A directory the calculation may write to, made on first use.

    A temporary directory made here is removed when the runner's call returns; a program called directly with RunContext() removes it itself (or uses its own temporary directory).

    device_ordinals() -> list[int] ¶

    The granted GPUs as CUDA device ordinals in this process, in grant order.

    def compute(
    self, inp: ProgramInput, ctx: RunContext | None = None

    """Evaluate the functions at the input's structure.

    Raises:
        ProgramError: The input is refused, or a function raised (kind
            ``internal``; the failed output holds its traceback).
    """

    # A runner hands on the plan it made.
    plan = ctx.plan if ctx is not None and ctx.plan is not None else self.plan(inp)
    assert inp.structure is not None
    x = np.asarray(inp.structure.geometry, dtype=float).reshape(-1, 3)
    provenance = Provenance(program=self.name, program_version=self.version())
    # What the runner granted; called directly, what the input asks for.
    threads = (ctx.threads if ctx is not None else None) or inp.keywords.get(
        "threads", 1
    )

        energy, gradient = self._energy_gradient(x.copy(), *given)
        values: dict[str, Any] = {"energy": float(energy)}
        if inp.calctype != CalcType.energy:
            values["gradient"] = np.asarray(gradient, dtype=float).reshape(-1, 3)
        if inp.calctype == CalcType.hessian:
            assert self._hessian is not None
            hessian = self._hessian(x.copy(), *given)
            values["hessian"] = np.asarray(hessian, dtype=float)
        results = SinglePointData(provenance=provenance, **values)
    except ProgramError:  # the function's own refusal or failure
        raise

        error = ErrorInfo(
            kind=ErrorKind.internal, message=f"{type(e).__name__}: {e}"
        )

            inp,
            error,
            traceback="".join(traceback.format_exception(e)),
            execution=ExecutionInfo(threads=threads),
        )
        raise ProgramError(error, output=out) from e
    return ProgramOutput(
        input_data=inp,
        success=True,
        results=results,
        resolved=plan.resolved,
        record=plan.record,
        execution=ExecutionInfo(
            threads=threads, timings={"total": time.perf_counter() - start}
        ),
    )

    def compute_many(self, requests: Sequence[Request]) -> list[Frame]:
    """Evaluate many geometries in one call to compute.

    Args:
        requests: The evaluations.

    Returns:
        One frame per request, in order.

    Raises:
        ProgramErrors: Some requests failed; ``results`` holds every frame.
    """
    if self._closed:
        raise RuntimeError("The session is closed.")
    frames: list[Frame | None] = [None] * len(requests)
    inputs: list[ProgramInput] = []
    places: list[int] = []
    for i, r in enumerate(requests):
        try:
            if r.outputs:
                raise ProgramError.of(
                    "unsupported", "per-request outputs need a program session"
                )
            inputs.append(self._input(r.positions, r.calctype, r.accuracy))
            places.append(i)
        except ProgramError as e:
            geometry = (
                self._structure.geometry if r.positions is None else r.positions
            )
            structure = self._structure.model_copy(
                update={
                    "geometry": np.asarray(geometry, dtype=float).reshape(-1, 3)
                }
            )
            frames[i] = failed_frame(structure, e, self.program)
    outputs = self._compute(inputs, raise_exc=False) if inputs else []
    for i, inp, out in zip(places, inputs, outputs, strict=True):
        try:
            if not out.success:
                frame = self._as_frame(out)
            elif inp.calctype == CalcType.hessian and out.results.gradient is None:
                frame = self._one(inp)
            else:
                frame = self._as_frame(out)
            frames[i] = frame
        except ProgramError as e:
            assert inp.structure is not None
            frames[i] = failed_frame(inp.structure, e, self.program)
    return ProgramErrors.check([f for f in frames if f is not None])
